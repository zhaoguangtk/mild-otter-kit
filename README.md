# mild-otter-kit



学习用的示例项目

## 用法

```bash
cat data.txt | cargo run
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 安装

```bash
git clone https://github.com/USER/mild-otter-kit.git
cd mild-otter-kit
cargo build --release
```

## 为什么写

现有的工具都太重，就想要个能管道拼接的小东西。
